Part 05 — Logika Kondisional

CASE
WHEN

Menambahkan logika kondisional (seperti if-else) langsung di dalam query SQL untuk mengklasifikasikan dan memberi label pada data secara otomatis.

QUIZ 1 CASE WHEN — Kategori Performa Order

CASE WHEN bekerja seperti if-else: MySQL mengevaluasi kondisi dari atas ke bawah dan menggunakan hasil dari kondisi pertama yang terpenuhi. Jika tidak ada yang cocok, ELSE menjadi nilai default.

Query ini juga menggunakan GROUP BY untuk mengelompokkan baris berdasarkan orderNumber dan SUM() untuk menjumlahkan total per order.

SQL
SELECT
    orderNumber,
    SUM(quantityOrdered * priceEach) AS total,
    CASE
        WHEN SUM(quantityOrdered * priceEach) >= 50000
            THEN 'Target Achieved'
        WHEN SUM(quantityOrdered * priceEach) <= 20000
            THEN 'Less performed'
        ELSE 'Follow Up'
    END AS remark
FROM orderdetails
GROUP BY orderNumber;

// LOGIKA KONDISI

IF total ≥ 50.000 → Target Achieved
ELIF total ≤ 20.000 → Less performed
ELSE (20.001 – 49.999) → Follow Up

QUIZ 2 CASE WHEN — Kategori Nilai Transaksi (High/Medium/Low)

Query ini mengkategorikan setiap baris transaksi secara individual (tanpa GROUP BY) ke dalam tiga segmen nilai. Operator BETWEEN pada kondisi Medium bersifat inklusif — nilai 100.000 dan 300.000 termasuk di dalamnya.

Hasil diurutkan berdasarkan kode_transaksi dan no_urut menggunakan ORDER BY dengan dua kolom sekaligus.

SQL
SELECT
    kode_transaksi, kode_pelanggan, no_urut,
    kode_produk, nama_produk, qty,
    (qty * harga) AS total,
    CASE
        WHEN (qty * harga) > 300000
            THEN 'High'
        WHEN (qty * harga) BETWEEN 100000 AND 300000
            THEN 'Medium'
        ELSE 'Low'
    END AS kategori
FROM ms_transaksi
ORDER BY kode_transaksi, no_urut;
