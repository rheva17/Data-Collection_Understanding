Part 03 — Filter Data

WHERE &
Operator Logika

Memfilter data menggunakan klausa WHERE dengan berbagai operator: perbandingan, AND, OR, kalkulasi kolom, dan pengurutan ORDER BY.

QUIZ 1 WHERE — Kondisi Tunggal

Klausa WHERE memfilter baris yang hanya memenuhi kondisi tertentu. Untuk nilai string/teks, gunakan tanda kutip tunggal (').

SQL
SELECT * FROM ms_produk
WHERE nama_produk = 'Tas Travel Organizer DQLab';

// Output — 1 row

no_urutkode_produknama_produkharga
7prod-07Tas Travel Organizer DQLab48000

1 row in set (0.01 sec)

QUIZ 2 WHERE dengan Operator OR

Operator OR digunakan ketika ingin memilih baris yang memenuhi salah satu dari beberapa kondisi. Cocok untuk mencari beberapa nilai dalam satu kolom.

SQL
SELECT * FROM ms_produk
WHERE nama_produk = 'Flashdisk DQLab 64 GB'
   OR nama_produk = 'Tas Travel Organizer DQLab'
   OR nama_produk = 'Gantungan Kunci DQLab';

// Output — 3 rows

no_urutkode_produknama_produkharga

7prod-07Tas Travel Organizer DQLab48000
8prod-08Gantungan Kunci DQLab15800

3 rows in set (0.00 sec)

QUIZ 3 WHERE dengan Operator Perbandingan (>)

Operator perbandingan seperti >, <, >=, <= digunakan untuk memfilter data numerik. Query ini mengambil semua produk dengan harga di atas 50.000.

SQL
SELECT * FROM ms_produk
WHERE harga > 50000;

QUIZ 4 WHERE dengan Operator AND

Operator AND mensyaratkan semua kondisi harus terpenuhi. Berbeda dengan OR yang cukup satu kondisi saja.

SQL
SELECT * FROM ms_produk
WHERE nama_produk = 'Gantungan Kunci DQLab'
  AND harga < 50000;

// Output — 1 row

no_urutkode_produknama_produkharga
8prod-08Gantungan Kunci DQLab15800

1 row in set (0.00 sec)

QUIZ 5 Kalkulasi Kolom + WHERE + ORDER BY DESC

Query ini menggabungkan tiga fitur sekaligus: membuat kolom kalkulasi baru (qty * harga) AS total, memfilter dengan WHERE, lalu mengurutkan hasil dari nilai terbesar ke terkecil dengan ORDER BY ... DESC.

SQL
SELECT kode_pelanggan, nama_produk, qty, harga,
       (qty * harga) AS total
FROM ms_transaksi
WHERE (qty * harga) >= 100000
ORDER BY total DESC;
ORDER BY DESC = dari besar ke kecil (Descending). ORDER BY ASC = dari kecil ke besar (Ascending), ini adalah default jika tidak ditulis.
