Part 09 — Export Data

Export
CSV

Mengekspor data dari tabel database ke format CSV (Comma-Separated Values) menggunakan fitur Export di phpMyAdmin.

TASK Export Tabel ke Format CSV

CSV (Comma-Separated Values) adalah format file teks sederhana di mana setiap baris merepresentasikan satu record dan setiap kolom dipisahkan oleh koma. Format ini sangat kompatibel dengan Excel, Google Sheets, dan berbagai tools analisis data.

Cara export via phpMyAdmin: pilih tabel → klik tab Export → pilih format CSV → klik Go.

// Langkah Export di phpMyAdmin

// STEPS
1 Buka phpMyAdmin → pilih database project_analisisdata
2 Klik nama tabel yang ingin diekspor (misal: customer)
3 Klik tab Export di menu atas
4 Pilih format CSV → klik tombol Go
5 File CSV akan otomatis terunduh. Lakukan untuk semua tabel.
