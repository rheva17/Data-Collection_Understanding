Part 04 — Built-in Functions

Fungsi
Bawaan MySQL

Memanfaatkan fungsi matematika (MOD, EXP), manipulasi string (UPPER, LOWER), dan fungsi agregat (MIN, MAX) yang sudah tersedia di MySQL.

QUIZ 1 Fungsi Matematika — MOD & EXP

MOD(x, y) — Menghitung sisa bagi dari x dibagi y (modulo). Contoh: MOD(55, 2) = 1, karena 55 dibagi 2 bersisa 1.

EXP(x) — Menghitung nilai eksponensial e (≈2.718) dipangkatkan x. Contoh: EXP(8) = 2980.95...

SQL
SELECT
    StudentID,
    FirstName,
    LastName,
    MOD(Semester1, 2) AS Semester1,
    Semester2,
    EXP(MarkGrowth) AS EXP_MarkGrowth
FROM students;

QUIZ 2 Fungsi String — UPPER & LOWER

UPPER(str) — Mengubah semua karakter dalam string menjadi huruf kapital. Contoh: 'Jose' → 'JOSE'.

LOWER(str) — Mengubah semua karakter dalam string menjadi huruf kecil. Contoh: 'Mohit' → 'mohit'.

Fungsi ini berguna untuk normalisasi data teks sebelum perbandingan atau tampilan yang konsisten.

SQL
SELECT
    StudentID,
    UPPER(FirstName) AS FirstName,
    LOWER(LastName)  AS LastName
FROM students;

// Output — 5 rows

StudentIDFirstNameLastName
1JOSEmohit
2LALAkarlina

5 rows in set (0.01 sec)

QUIZ 3 Fungsi Agregat — MIN & MAX

Fungsi agregat bekerja pada sekumpulan baris dan menghasilkan satu nilai ringkasan. MIN() mengambil nilai terkecil, MAX() mengambil nilai terbesar dari keseluruhan data kolom.

Perhatikan bahwa hasilnya hanya 1 baris meski tabel memiliki 5 baris — karena fungsi agregat merangkum seluruh data.

SQL
SELECT
    MIN(Semester1) AS Min1,
    MAX(Semester1) AS Max1,
    MIN(Semester2) AS Min2,
    MAX(Semester2) AS Max2
FROM students;

// Output — 1 row (ringkasan)

Min1Max1Min2Max2
45.32 92.25 50.25 90.75

1 row in set (0.01 sec)

Fungsi agregat lain yang sering dipakai: SUM() untuk jumlah total, AVG() untuk rata-rata, COUNT() untuk menghitung jumlah baris.
