Part 01 — Dasar SQL

SELECT &
LIMIT

Pengenalan struktur tabel dan cara mengambil data menggunakan SELECT dengan pembatasan baris menggunakan LIMIT.

QUIZ 1 Komponen Dasar Tabel

Sebelum menulis query, kita harus memahami empat komponen dasar struktur tabel dalam basis data relasional:

A = Column — Kolom merepresentasikan atribut/field dari tabel, seperti nama_produk atau harga.

B = Row — Baris adalah satu record/entri data dalam tabel.

C = Data — Nilai aktual yang tersimpan di dalam setiap sel.

D = Table — Kumpulan baris dan kolom yang merepresentasikan satu entitas.

QUIZ 2 SELECT Kolom Tertentu

Perintah SELECT digunakan untuk mengambil data dari tabel. Dengan menyebutkan nama kolom secara spesifik, kita hanya mengambil data yang dibutuhkan, bukan semua kolom.

SQL 
-- Melihat semua kolom terlebih dahulu
SELECT * FROM ms_produk;

-- Mengambil hanya kolom nama_produk dan harga
SELECT nama_produk, harga FROM ms_produk;
Gunakan SELECT * hanya saat eksplorasi awal. Untuk produksi, selalu sebutkan kolom spesifik agar query lebih efisien.

QUIZ 3 SELECT dengan LIMIT

Klausa LIMIT membatasi jumlah baris yang dikembalikan oleh query. Ini sangat berguna saat tabel memiliki ribuan baris dan kita hanya perlu melihat sebagian kecil sebagai preview atau pengujian.

SQL 
SELECT nama_produk, harga
FROM ms_produk
LIMIT 5;

// Output — 5 rows (dibatasi)

nama_produkharga
Kotak Pensil DQLab62500
Flashdisk DQLab 64 GB55000
Gift Voucher DQLab 100rb100000
Flashdisk DQLab 32 GB40000
Gift Voucher DQLab 250rb250000

5 rows in set (0.00 sec)
