Part 10 — Agregasi Lanjutan

GROUP BY
& HAVING

Mengelompokkan data berdasarkan kolom tertentu, menghitung agregat per kelompok, lalu memfilter kelompok menggunakan HAVING.

QUIZ 1 — Query 1 GROUP BY + SUM

GROUP BY mengelompokkan baris yang memiliki nilai sama pada kolom yang ditentukan. Fungsi agregat seperti SUM() kemudian dihitung per kelompok — bukan untuk keseluruhan tabel.

Tanpa GROUP BY, SUM() akan menjumlahkan seluruh baris. Dengan GROUP BY, SUM() menjumlahkan per ordernumber.

SQL
SELECT
    ordernumber,
    SUM(quantityordered) AS itemscount,
    SUM(quantityordered * priceeach) AS total
FROM orderdetails
GROUP BY ordernumber;

QUIZ 1 — Query 2 GROUP BY + HAVING

HAVING adalah filter yang bekerja setelah GROUP BY — berbeda dengan WHERE yang memfilter baris individual sebelum pengelompokan. HAVING memfilter kelompok berdasarkan hasil agregasi.

Aturan penting: WHERE tidak bisa menggunakan alias dari kolom agregat, tapi HAVING bisa.

SQL
SELECT
    ordernumber,
    SUM(quantityordered) AS itemscount,
    SUM(quantityordered * priceeach) AS total
FROM orderdetails
GROUP BY ordernumber
HAVING total > 1000;

WHERE

Memfilter baris sebelum pengelompokan. Tidak bisa menggunakan kolom agregat (SUM, COUNT, dll).

HAVING

Memfilter kelompok setelah pengelompokan. Bisa menggunakan alias kolom agregat.

QUIZ 1 — Query 3 HAVING dengan Kondisi Ganda (AND)

HAVING bisa menggunakan beberapa kondisi sekaligus dengan operator AND/OR, sama seperti WHERE. Query ini mencari order dengan total di atas 1.000 dan jumlah item di atas 600.

SQL
SELECT
    ordernumber,
    SUM(quantityordered) AS itemscount,
    SUM(quantityordered * priceeach) AS total
FROM orderdetails
GROUP BY ordernumber
HAVING
    total > 1000
    AND itemscount > 600;

QUIZ 2 JOIN + WHERE + GROUP BY + HAVING

Query paling kompleks — menggabungkan empat klausa sekaligus. Urutannya: JOIN dulu untuk menggabungkan tabel, WHERE untuk filter baris awal, GROUP BY untuk mengelompokkan, lalu HAVING untuk filter kelompok.

Urutan eksekusi SQL: FROM → JOIN → WHERE → GROUP BY → HAVING → SELECT → ORDER BY

SQL
SELECT
    o.ordernumber,
    o.status,
    SUM(od.quantityordered * od.priceeach) AS total
FROM orders o
JOIN orderdetails od
    ON o.ordernumber = od.ordernumber
WHERE o.status = 'Shipped'
GROUP BY o.ordernumber, o.status
HAVING total > 1500;
