Part 07 — Menggabungkan Query

UNION &
Subquery

Menggabungkan hasil dari beberapa query menggunakan UNION ALL, serta memfilter data menggunakan operator IN dengan subquery atau daftar nilai.

QUIZ 1 UNION ALL — Gabungkan Dua Tabel

UNION ALL menggabungkan hasil dari dua query menjadi satu hasil. Berbeda dengan UNION biasa, UNION ALL mempertahankan semua baris termasuk duplikat. Kedua query yang digabungkan harus memiliki jumlah dan tipe kolom yang sama.

SQL
SELECT *, qty * harga AS total
FROM tabel_a
WHERE kode_pelanggan = 'polibest03'

UNION ALL

SELECT *, qty * harga AS total
FROM tabel_b
WHERE kode_pelanggan = 'polibest03';
UNION menghapus duplikat (lebih lambat). UNION ALL mempertahankan semua baris (lebih cepat). Gunakan UNION ALL jika yakin tidak ada duplikat atau duplikat memang diperlukan.

QUIZ 2 JOIN + WHERE IN — Filter Berdasarkan Daftar Nilai

Operator IN memungkinkan filter berdasarkan daftar nilai sekaligus, lebih ringkas dibanding banyak kondisi OR. Query ini mencari pelanggan yang pernah membeli salah satu dari tiga produk tertentu, menggunakan JOIN antara tabel pelanggan dan tabel penjualan.

DISTINCT ditambahkan agar satu pelanggan yang membeli beberapa produk dari daftar tidak muncul berulang.

SQL
SELECT DISTINCT
    p.kode_pelanggan,
    p.nama_customer,
    p.alamat
FROM ms_pelanggan p
JOIN tr_penjualan t
    ON p.kode_pelanggan = t.kode_pelanggan
WHERE t.nama_produk IN (
    'Kotak Pensil DQLab',
    'Flashdisk DQLab 32 GB',
    'Sticky Notes DQLab 500 Sheets'
);

QUIZ 3 UNION ALL dari Dua Tabel Berbeda + Filter BETWEEN

Query ini menggabungkan produk dari dua tabel berbeda (ms_produk_1 dan ms_produk_2) dengan kondisi filter berbeda di setiap bagian. Operator BETWEEN pada string bekerja berdasarkan urutan alfanumerik.

SQL
SELECT nama_produk, kode_produk, harga
FROM ms_produk_1
WHERE harga < 100000
  AND kode_produk BETWEEN 'prod-01' AND 'prod-05'

UNION ALL

SELECT nama_produk, kode_produk, harga
FROM ms_produk_2
WHERE harga < 50000
  AND kode_produk BETWEEN 'prod-06' AND 'prod-10';
