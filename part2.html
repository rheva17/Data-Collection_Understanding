Prefix & Alias

Menghilangkan duplikasi data, menggunakan prefix nama tabel, dan memberikan alias pada kolom maupun tabel.

QUIZ 1 SELECT DISTINCT

DISTINCT menghilangkan baris duplikat dari hasil query. Tabel ms_pelanggan memiliki 12 baris, namun setelah DISTINCT diterapkan hasilnya menjadi 10 baris — karena beberapa nama customer muncul lebih dari sekali (misal: Tomy Sinaga dan Unang Handoko).

SQL 
-- Tanpa DISTINCT: 12 baris (ada duplikat)
SELECT * FROM ms_pelanggan;

-- Dengan DISTINCT: 10 baris (duplikat dihapus)
SELECT DISTINCT nama_customer, alamat
FROM ms_pelanggan;

QUIZ 2 Prefix Nama Tabel

Penulisan kolom dengan prefix nama tabel menggunakan titik (.) memperjelas kolom berasal dari tabel mana. Ini sangat penting saat melakukan JOIN antara dua tabel yang memiliki nama kolom sama.

QUIZ 3 & 4 Alias Kolom — AS dan Tanpa AS

Alias memberikan nama sementara pada kolom di hasil query. Ada dua cara penulisan yang menghasilkan output identik: menggunakan kata kunci AS (Quiz 3) atau langsung menulis nama alias setelah nama kolom (Quiz 4).

SQL 
-- Quiz 3: Dengan kata kunci AS
SELECT no_urut AS nomor, nama_produk AS nama
FROM ms_produk;

-- Quiz 4: Tanpa kata kunci AS (hasil sama persis)
SELECT no_urut nomor, nama_produk nama
FROM ms_produk;
Penggunaan AS bersifat opsional namun sangat disarankan untuk keterbacaan query, terutama saat bekerja dalam tim.

QUIZ 5 Kombinasi Prefix Tabel + Alias

Prefix nama tabel dan alias kolom bisa digabungkan dalam satu query untuk hasil yang lebih ekspresif dan tidak ambigu.

SQL 
SELECT ms_produk.harga AS harga_jual
FROM ms_produk;
QUIZ 6 & 7 Alias untuk Tabel

Tidak hanya kolom, tabel pun bisa diberi alias. Alias tabel ditulis langsung setelah nama tabel (tanpa AS, meski AS juga boleh). Alias tabel sangat berguna dalam konteks JOIN atau subquery untuk mempersingkat penulisan.

SQL 
-- Quiz 6: Semua kolom dengan alias tabel t2
SELECT * FROM ms_produk t2;

-- Quiz 7: Kolom tertentu dengan alias tabel t2
SELECT nama_produk, harga
FROM ms_produk t2;
Alias tabel tidak mengubah nama tabel asli di database, hanya berlaku selama eksekusi query tersebut.
